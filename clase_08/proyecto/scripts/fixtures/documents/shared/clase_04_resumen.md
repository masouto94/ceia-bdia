# Clase 04 — Bases de datos NoSQL y modelado documental

Introducción a las bases de datos NoSQL usando MongoDB, migrando el mismo caso de experimentos de IA desde un modelo relacional a uno documental.

## Temas vistos

- Comparación explícita entre modelo relacional y modelo documental.
- Operaciones CRUD, filtros y agregaciones (`aggregate`) en MongoDB.
- Patrones de modelado: documentos embebidos vs. referencias entre colecciones.
- Índices y análisis de consultas con `explain` en MongoDB.
- Herramientas: MongoDB 8 sobre Docker, MongoDB Compass como cliente principal, Mongo Express como visor web opcional.

## Práctica

Se transformó el esquema relacional de experimentos de IA en colecciones documentales, ejercitando modelado, consultas, agregaciones e índices directamente con MongoDB Compass.
